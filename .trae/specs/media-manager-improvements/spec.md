# MediaManager - 产品需求文档

## Overview
- **Summary**: 根据架构报告的建议，对 MediaManager 项目进行关键改进，包括错误处理、性能优化、安全性和进度反馈等方面的增强。
- **Purpose**: 解决架构报告中识别的潜在问题，提高系统的可靠性、性能和用户体验。
- **Target Users**: MediaManager 的最终用户和开发者。

## Goals
- 实现统一的错误处理机制
- 提高文件扫描和索引的性能
- 增强系统的安全性
- 改善 UI 响应性和用户反馈
- 建立基本的测试框架

## Non-Goals (Out of Scope)
- 全面重构整个系统架构
- 添加新的核心功能（如云同步）
- 完整的插件架构实现
- API 接口开发
- 第三方集成

## Background & Context
根据架构报告的分析，MediaManager 当前存在以下主要问题：
1. 部分服务缺少详细的错误处理和异常管理
2. 对于大型媒体库，扫描和索引可能会很慢
3. UI 响应性问题，长时间运行的操作可能导致 UI 冻结
4. 缺乏单元测试和集成测试
5. 存在潜在的安全风险

## Functional Requirements
- **FR-1**: 实现统一的错误处理机制，提供详细的错误信息和恢复策略
- **FR-2**: 实现增量扫描功能，只扫描变化的文件
- **FR-3**: 为长时间运行的操作提供进度反馈机制
- **FR-4**: 实现文件路径验证，防止路径遍历攻击
- **FR-5**: 建立单元测试项目框架，为核心服务添加基本测试

## Non-Functional Requirements
- **NFR-1**: 增量扫描应减少扫描时间 80% 以上（针对已有媒体库）
- **NFR-2**: 所有长时间运行的操作应提供实时进度更新
- **NFR-3**: 错误信息不应泄露敏感信息（如文件系统结构）
- **NFR-4**: 核心服务的测试覆盖率应达到 50% 以上

## Constraints
- **Technical**: 保持现有的 .NET 8.0+ 技术栈和分层架构
- **Business**: 维护向后兼容性，不破坏现有功能
- **Dependencies**: 使用现有依赖库（EF Core, Serilog, 等），不引入新的重大依赖

## Assumptions
- 现有代码库结构保持不变
- 用户数据可以无缝迁移
- FFmpeg/FFprobe 依赖仍然可用
- SQLite 作为主要存储引擎保持不变

## Acceptance Criteria

### AC-1: 统一错误处理
- **Given**: 系统运行中发生错误
- **When**: 任何服务抛出异常
- **Then**: 错误被正确捕获、记录，并以友好的方式向用户展示，不泄露敏感信息
- **Verification**: `programmatic` + `human-judgment`
- **Notes**: 错误信息应包含足够的技术细节用于调试，但隐藏敏感路径信息。

### AC-2: 增量扫描功能
- **Given**: 已有媒体库已完成完整扫描
- **When**: 用户再次触发扫描
- **Then**: 系统仅扫描新增、修改或删除的文件，大幅缩短扫描时间
- **Verification**: `programmatic`
- **Notes**: 使用文件的最后修改时间和大小进行检测。

### AC-3: 进度反馈机制
- **Given**: 用户触发长时间运行的操作（如完整扫描）
- **When**: 操作进行中
- **Then**: UI 显示实时进度信息，包括当前处理的文件、进度百分比和估计剩余时间
- **Verification**: `human-judgment` + `programmatic`
- **Notes**: 进度信息应通过事件或回调机制提供。

### AC-4: 文件路径验证
- **Given**: 用户输入或系统接收文件路径
- **When**: 路径被用于文件系统操作
- **Then**: 路径经过验证，防止路径遍历攻击，确保在允许的目录范围内
- **Verification**: `programmatic`
- **Notes**: 验证应防止如 "../" 等路径遍历尝试。

### AC-5: 测试框架建立
- **Given**: 开发环境
- **When**: 运行测试套件
- **Then**: 核心服务有基本的单元测试覆盖，测试可以正常执行并报告结果
- **Verification**: `programmatic`
- **Notes**: 至少为文件扫描、哈希计算和元数据提取服务添加测试。
