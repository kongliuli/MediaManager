## 概述

MediaManager 有两个前端版本：
1. **WPF 桌面版** - Windows 原生桌面应用程序
2. **Blazor Server Web 版** - 现代 Web 应用程序

两个版本共享相同的核心服务和数据访问层，但使用不同的 UI 技术。

### 设计理念
- **简洁直观** - 清晰的导航和操作流程
- **响应式** - 适配不同屏幕尺寸
- **现代化** - 使用最新的 UI 技术和设计风格
- **可扩展** - 支持插件和组件系统

### 设计模式

#### Blazor - 组件化模式
- 使用 Razor 组件
- 数据绑定和事件处理
- 服务注入
- 状态管理

#### WPF - MVVM 模式
- View - XAML 视图
- ViewModel - C# 视图模型
- Model - 数据模型
- INotifyPropertyChanged - 属性更改通知
- ICommand - 命令绑定
